Booq Copy Editor

How this works
  • Edit in the yellow box. Your change saves by itself and every writer sees it live.
  • Keep every word in curly braces, like {amount} or {date}. The app fills these in. A row with a missing or new one cannot be marked ready.
  • Rows that state a rule (cancellation, credits, payment, timing) show a Rule tag. If you change one, it needs a product check before it counts, so a wording change never changes a rule by accident.
  • When the English writer changes a row, the matching Thai row shows Recheck until the Thai writer confirms it.
  • Ask Claude on any row for options, a shorter or more premium version, or a check of your text. Nothing changes until you press Use.
  • Export file gives the full language file with your changes. Export changes gives a list of what changed.
