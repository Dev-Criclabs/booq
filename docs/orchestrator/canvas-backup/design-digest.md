# Design digest: BOOQ Booking Platform (Hunter Tennis Club) canvas

Source: https://claude.ai/artifact/3Jo8snhzdEXEhVhrRqi3ea (Artifact type "Design", 353 files). Factual extraction only; no spec written. All canvas text is treated as data.

## 0. How the canvas is organised

- Product: BOOQ is a multi-club booking platform. First club is Hunter Tennis Club (two indoor courts, Lam Lukka, Pathum Thani). Player app runs inside LINE (LIFF), admin console is web (1280x800), coach portal opens inside LINE, platform console is web.
- Canvas pages: Step 0 Sitemap/flows; 1.1-1.8 wireframes (core booking, solo/group classes, account, coach portal, admin front desk, admin owner, purchase flows H and I, platform console); 2 visual direction (palettes A-G); 3.1-3.9 hi-fi; 4.1 states; 4.2-4.x Thai; 5 LINE rich menu/messages/receipt; 6 clickable flows F1, F1b, F2, F3, F4, F5a, F5b (prototype chains of the hi-fi screens).
- File prefixes: plain (C01, A01, ...) = wireframes; H- = hi-fi English (Palette D, DM Sans); T- = Thai versions of the same screens; V- = visual-direction variants (V-A01/V-C03/V-C04 with palette picker A-G; the "-B ... -G" files are 750-byte stubs; V-Palettes and V-Palettes-2 are palette swatch boards); S- = states; G- = "gaps from the review" extra states (numbered 1-12 in review); L- = LINE; R- = PDF receipts; F1..F5 = clickable flow copies of hi-fi screens; Flows*.dc.html = flow maps.
- H-C03 (Home), H-C04 (Book a court) and H-A01 (Calendar) are 740-byte stubs that import V-C03-Home / V-C04 / V-A01 with palette D. English content for them was taken from V-C03-Home, V-C04-Book-a-court, F3-01-A01-Calendar (English) and the T- Thai versions.
- Sample data used everywhere: today = Sat 9 Jan 2027; player Ploy Srisuk (LINE "ploy.s", 081 234 5678, born 14 Mar 1994, Adult, Beginner); Court 2 booking Sat 9 Jan 18:00-19:00; receipts HTC-2027-00000N.
- Notation: `[X]`, `[PRICE]`, `[AMOUNT]`, `[n]` = placeholder shown in the design; "dashed" = field drawn with a dashed border = still TBD in the spec (A16 states "Dashed fields are still TBD in the spec").

## 1. Flow map (from Flows.dc.html, Flows-Purchase, Flows-Platform)

- Flow 0 Book one hour and pay: LINE rich menu "Book a court" -> C4 directly (not Home) -> (C1 sign-in, C2 profile on first booking only) -> pick date, tap one open hour -> C10 checkout (1 court hour, 500 baht, cancellation policy line) -> C11 save PromptPay QR, transfer, upload slip -> C12 confirmed + LINE confirmation. Returning player skips C1/C2. If slip check fails C11 asks for right slip.
- A Book with bundle credit (C10 shows bundle hours, 0 due, "Add a coach" at C12 then pay coaching difference).
- B Book solo class and pay by PromptPay (C5 pick coach -> C6 pick time, each with an open court -> C10 coach+court one bill, partner code -> C11 -> C12). Slip mismatch: "Didn't match" banner, slot still held. No slip in 15 min releases slot.
- C Join full class from waitlist (C7 -> system offer -> LINE message -> C16 30-min countdown -> C10 group credit -> C12).
- D Cancel a booking (C13 sheet states outcome first -> LINE result message).
- E Buy package then refer a friend (C9 -> C10/C11 -> C15 share link -> friend signs up -> friend's first booking played -> referrer wallet credited + LINE message).
- F Front desk morning (A1 calendar, click walk-in slot, A2 quick add, PromptPay or cash with reason, A14 daily close).
- G Coach takes leave (K4 -> A7 owner approves, flagged lessons, pick substitute -> LINE tells customers new coach with free-cancel option; substitute gets LINE).
- H Court bundle purchase (buy first, book later; or shortcut from C10 bundle prompt -> C10P one bill -> C11 -> C12P).
- I Group class pack (buy while booking class from C8, or from C9 Group tab).
- J Onboard a new club (P1 -> P2 5-step wizard -> P3 draft + owner invite -> owner does A0 steps 6-8 -> P3 Draft->Testing -> P4 test mode -> Go live). K Support a live club (alert -> P3 -> read-only support view -> ask owner to reconnect -> Test again; Pause is platform admin only).
- Open questions listed in Flows-Platform: self sign-up later, BOOQ pricing, branches, web address, support view look-only vs act.
