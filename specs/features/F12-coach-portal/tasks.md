# F12 Coach portal · Tasks

Status: **Approved 31 Oct 2026 (D171).** Drafted 31 Oct 2026 from the approved design (`design.md`, gate 2, D171) and the approved requirements (`requirements.md`). Rules for every task (CLAUDE.md): one task per run; write the tests from the acceptance criteria first, then the code; run tests and type checks before ticking; the commit message starts with the requirement IDs, for example `CPORT-05 mark attendance after the hour has ended`. A merged migration is never edited. New text goes in `locales/pending/F12.json` (D81); no user facing text in code.

Roles: **BE-C** back end (database, functions, routes), **FE-A** front end admin and coach, **QA**, **Content**.

Depends on: F01 (roles, route wrapper, blind suite, anonymise handlers); F07 (`coach`, `coach_availability_rule`, `coach_leave`, `app.set_availability`, `app.request_leave`, routes `/coach/availability` and `/coach/leave`, T12); F08 (`class_session`, seats); F10 (`app.enqueue_message`, `session_change`, `leave_decision`, message facts); F13 (`app.payout_figures`, `app.my_payouts`, T10). Migration numbers 1201 to 1208 (the F12 block), one task per file, rising in task order: T01 1201, T02 1202, T03 1203, T04 1204, T05 1205, T06 1206, T07 1207 (the rest cap read), T10 1208.

**Cross-feature tasks (named here, owned by other lists, for the orchestrator):** F10 follow up, after T06: `app.message_facts` and the `session_change` builder carry the `change` parameter (`booked`, `moved`, `cancelled`) and the writers give the wording (Content).
